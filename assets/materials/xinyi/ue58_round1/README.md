# UE 5.8 round 1 test inputs

Only two runtime PNGs were extracted from Draft PR #62 at
`b0e00f2256bfe67ba76798d73450fa3c5412930f`. The scene branch remains based on
`ede7960d8ec05b2aa521b1e4c65b5bbd667c456d`. PR #62 and its PR #14 base were
not merged or cherry-picked. `source.json` records the exact source paths,
manifest hash, PNG hashes, dimensions and per-channel ranges.

The original provenance and usage conditions are retained in
[PR62_SOURCES.md](PR62_SOURCES.md). The complete source package remains in
[PR #62](https://github.com/eddy121384-ui/air-combat-world/pull/62).

Both images are RGBA8 **data**, including Alpha. They are not albedo or opacity.
The isolated `/Game/XinyiMaterialAB` imports use sRGB OFF, Masks compression,
`compression_no_alpha=False`, Wrap U/V, and Simple Average mip generation.
No normal-map compression, opacity connection, decal, or per-channel texture
fetch is used.

The experiment uses a 32 m period and `(sample * 255 - 128) / 24` decoding.
Facade V is negative height, so PNG-down corresponds to gravity; only U is
mirrored. Huaxia has 0.6 of the old-apartment weight. The test changes old-stock
solid-wall colour/roughness and flat-roof colour/roughness. Windows, cages,
AC, ground-floor shop bands, sheet-roof props, modern/premium facades, schools,
hero, terrain and trees keep their baseline material paths or masks.

The surface expressions are generated by
`tools/lookdev/material_round1_shader.py` inside a separate test material.
`tools/lookdev/shaders/xinyi_city.hlsl`, the baseline material and the saved
level are not rewritten. Captures apply transient component overrides to the
25 Look tiles and never save the world.

This is an artistic review candidate, not a production integration or mobile
performance result. See `docs/xinyi-material-ue58-round1-result.md` for the
actual engine captures, receipts, limitations and one recovered shutdown failure.
