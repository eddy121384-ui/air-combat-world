# 北台灣植被圖鑑與樹種資產優先序 v1

用途：供 Skyfront Homeland 未來 Unreal 環境美術選樹、設計林冠與安排製作順序。**這是附查證缺口的研究草案，不是已驗證的植被分布圖。** 不新增地圖範圍、不生成植被、不變更場景；不收錄照片、蕨類、青苔、低矮灌木或林下裝飾。

## 2. 證據怎麼讀

- **A：直接核對到的局部證據。** 有座標、海拔與植群矩陣的研究樣區；只對該樣區的記錄有效，不直接形成面狀林分界線。
- **B：有可追溯來源、但有限制。** 官方資料的公開衍生快照、歷史目錄或 repo 既有研究轉述；須保留日期、抽樣與轉錄限制。
- **C：配置候選／待查。** 尚未讀到該地原始植群調查、林型圖或樹籍內容。不能據以宣稱「主要樹種」、密度、比例或精確分布。
- **V：美術工作值。** 表中樹高、冠形與季相供初期 brief 使用；除特別標明，**不是本輪野外測量，也尚未逐種經植物誌原站覆核**。正式製作前仍須確認種級身分及形態參考。

本輪嘗試林業保育署、林試所、陽明山國家公園、台灣植物資訊整合查詢系統及地方開放資料原站，均遇代理網路政策 HTTP 403。以下明列已讀的研究資料／文字轉錄與尚未讀的原站；不把轉述當成已讀論文。沒有使用物種出現點來推估全區林分覆蓋。

| 核心內復興／烏來較高山地、拉拉山—塔曼山；重點樣區 1,700–2,110 m | 先查雲霧、迎風／背風、稜谷與歷史干擾，再辨認闊葉、針闊混合與局部針葉成分 | 扁柏、鐵杉、水青岡、昆欄樹的樣區成分 **A**；群落多邊形及天然／人工界線仍待查 [E1][E2] | 高低與冠形交錯；局部針葉突出、局部落葉色塊；不做同高、同錐形的均勻森林 |
| 既有 224 km 世界內、核心／生產區以外高山遠景 | 高山植被與裸岩只影響遠景色帶；不能因遠景含雪山就新增可近看冷杉林 | 遠景地形範圍為 repo 證據；冷杉、玉山箭竹等精確植被帶本輪 **C** | 林線、開闊高山面與裸岩的大尺度明暗；暫不排冷杉／高山微觀資產 |

天然、次生、人工是**林分形成／經營狀態**，不能由樹種名稱單獨推定。同一地區也可能三者並存。迎風坡不一定沒有樹，背風坡也不一定是成熟天然林；造林與農業邊界須另找證據。

排序依「能補足哪一種空中景觀」與證據成熟度，**不是實測面積排名，也不是資產製作放行單**。

| P1-1 | **榕樹** | 台北樹籍有直接衍生證據；大型寬冠補都市、公園與寺廟輪廓，與紅楠分形 | 植物誌形態＋至少具名的道路／公園參考；其他城市另核 |
