# 迭代紀錄（真實 WebGL 截圖，每輪看圖後再改）

每輪都用 `tools/sky-capture.mjs --stills` 對五條路線各取 0／50／100% 三個時刻，看完整張圖再決定下一步。
接觸表：[orbit180-050](iterations/orbit180-050-rounds.jpg)、[sidepass-000](iterations/sidepass-000-rounds.jpg)、
[approach-050](iterations/approach-050-rounds.jpg)。各輪雲的位置可能不同（形狀文法改變會重排亂數，R15 起已分離佈局與形狀亂數）。

| 輪 | 看到的問題 | 判斷 | 改了什麼 |
|---|---|---|---|
| R0 | 整片天空只有海和天，雲完全不見 | 不是美術問題 | billboard 基底外積順序反了，quad 全被背面剔除 |
| R1 | 三維結構、海面雲影都對，但雲是一顆顆薰衣草泡泡，雲海像水母 | 方向對、畫法錯 | 色階重做；質量法線權重提高 |
| R2–R3 | 還是泡泡，球與球之間一圈圈明暗 | **每顆球的「太陽遮蔽」是常數**，等於把每顆球塗成不同色塊 | 改成一次性 sun-view 深度圖，遮蔽在空間中連續 |
| R4 | 大塊受光／背光出現，開始像畫；側掠的雲牆整面變暗 | 以為是 bug | CPU 光線追蹤證明是真的投影：第四座塔正好擋在主塔的太陽方向上（[除錯圖](iterations/occlusion-debug-sidepass.jpg)）。改佈局，加「太陽走廊」規則 |
| R5 | 雲海筏改成扁橢球，像真正的層積雲；但每顆 billow 邊緣有白色虛線 | 先懷疑陰影 | 逐項關閉 shader 項：關 sun-depth 時線消失 → 每顆 billow 自己遮自己；**以解析式扣除 billow 自身弦長** |
| R6 | 白虛線還在 | 再排除 | 天空換洋紅無變化；**頁面背景換洋紅後線變洋紅** → canvas 是 alpha:true，alpha-to-coverage 的半覆蓋讓網頁背景透出來（[證據](iterations/halo-canvas-alpha-proof.png)）。iPhone 一樣會中 |
| R7 | 白線消失，乾淨的手繪感受光面 | ✓ | 不透明 drawing buffer＋puff pass 保留目標 alpha；fringe 像素改投影到真實輪廓點 |
| R8–R9 | 近看像「氣球」；微浮雕讓晨昏線長出豹紋 | 浮雕不能動到明暗分界 | 微浮雕改成只調明度；陰影中每顆 billow 保留天光頂部 |
| R10 | 順光時整座塔一片奶油色，沒有形體 | 動畫背景會畫凹痕 | crevice（billow 轉入雲體一側）＋暖頂冷底漸層；8 次 hash 雜訊換成 64³ 預烘 3D 貼圖 |
| R11–R12 | 片段量太高：近塔時每像素 14.8 次 | 手機不能接受 | 扁雲海筏改扁 quad；**外露比例 <9% 的 billow 剔除**（生成 4.5 萬、保留 2 萬），每像素降到 6 次以下，畫面不變 |
| R13 | 均勻分布的小 billow 變成坑洞；主塔變雪人 | 形狀文法問題 | |
| R14–R15 | 加底裙、平滑收窄的主柱、較深的突出：**第一次像真正的濃積雲** | ✓ | 逐 billow 造形隨螢幕尺寸連續減弱；佈局／形狀亂數分流 |
| R16–R17 | 穿雲：暗面雲牆 → 白霧一格跳色；出雲一格切換 | 穿入穿出的節奏不對 | 霧色由相機處日照決定；非對稱時間濾波；出雲後殘霧改成短程薄紗（[前](iterations/traverse-before-fog-redesign.jpg)／[後](iterations/traverse-after-fog-redesign.jpg)） |
| R18 | 雲海頂近距出現陰影階梯；雲底天花板太紫 | 細節 | PCF 以世界雜訊旋轉；雲底改灰藍＋厚度明暗；小 billow 的 crevice 減弱 |

被否決的方向（試過或推演後放棄）：

- **體積 ray-march**：Animfix 已證明成本與棉花糖問題，不重做。
- **等值面雲殼**：B2 已證明「把光當材質」會讀成岩石。
- **四邊形放在球前緣、不寫 frag depth（換 early-z）**：球與球的交線會隨視角滑動，破壞一致性。
- **每顆 billow 的常數遮蔽／天光**：R2–R3 的泡泡來源。
