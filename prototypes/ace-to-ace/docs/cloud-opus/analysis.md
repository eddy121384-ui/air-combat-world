# 為什麼 B1／Animfix／B2 無法同時兼顧美感與空間一致性

基準：B1 `996329258379383f6ed1d8bdb4ea992589be6c14`。以下判斷來自閱讀三個分支的程式與文件、
對照它們提交的同場景截圖（`side-pass`、`turn180`、`inside`），不是重跑它們的效能測試。

## 動畫電影的雲，美在哪三件事

把 R2 天空畫和日本動畫電影背景裡的積雲拆開看，好看的部分幾乎都落在三件事：

| 要素 | 畫面上長什麼樣 | 誰負責 |
|---|---|---|
| **形狀語言** | 平坦的凝結底、往上堆疊的塔、輪廓由大到小的花椰菜狀凸起（分形） | 幾何 |
| **明暗設計** | 少數幾塊大的受光／背光面；奶油白亮面、桃色晨昏線、帶顏色的薰衣草藍陰影；逆光時質量輪廓的銀邊 | 光，不是材質 |
| **邊緣設計** | 受光冠部銳利、背光與雲底柔；遠處被空氣吃掉 | 邊緣與大氣 |

三版各自只拿到其中一部分，而且拿到的方式彼此衝突。

## 三版各自卡在哪

**B1（靜態極美，動態穿幫）。** 三件事都在 2D 原畫裡，所以靜態截圖好看。但一張畫只是「某個視角的投影」。
`normalize(eye-pCenter)` 讓畫片轉向觀察者、仰角換 side/top/base 圖、整片依中心距離淡出——不論怎麼修，
「繞著一張 2D 投影看」本身就不成立。180° 繞行與穿入時出現的翻面、換剪影、融化，是表示法的必然，不是參數問題。

**Animfix（動態穩定，棉花糖）。** 改用 B0 密度場的 3D cache 加世界座標筆觸，一致性問題消失。
但形狀來自 B0 的 27 個平滑橢球，體積積分讓所有邊緣都軟，光照是物理近似——
形狀語言、明暗設計、邊緣設計三者一起消失，只剩一團均勻的柔霧。

**B2（固定雲殼，漂浮岩石）。** 用等值面建出封閉殼並把原畫三向投影上去。殼依舊長自 B0 橢球（加雕刻），
所以剪影是大圓石；更關鍵的是：**插畫裡的明暗原本是「光」，被投影到 3D 表面後被讀成「材質」**——
同一個暗面筆觸，貼在不隨光改變的固定曲面上，看起來就是岩石或雪的紋理。

## 共同根因

1. **形狀的來源錯了。** 三版都試著讓 B0 的橢球密度場長出動畫雲的樣子。橢球怎麼算都還是橢球：
   柔就是棉花糖，硬就是石頭。動畫雲的形狀語言必須被「設計」出來，不能從平滑場裡「浮現」。
2. **把光當成材質。** 插畫的冷暖明暗是畫家對光的設計；把它當貼圖搬到 3D，只會在第一個視角正確。
3. **把視角一致性和美術風格當成同一個技術選擇。** 事實上可以分開：幾何負責一致性與剪影，
   shader 負責明暗設計，遠方畫負責無限遠的構圖。

## 本輪的重新定義

> 形狀用 3D 生成，光用 shader 畫，遠方交給畫。

- 雲是由**橢球 billow** 分形堆疊的 3D 物件（塔 → 中型 billow → 冠部小 billow），共用平坦凝結底。
  手工佈局主塔與構圖走廊，隨機只負責細節。
- 每個 billow 是旋轉不變的形體，在面向相機的 quad 上做精確 ray-cast：**畫的是幾何，不是圖片**，
  所以從任何角度、任何距離都是同一個物體——這正是 B1 缺的，但不必付出 Animfix 的體積積分成本。
- 明暗採 NPR 的 normal transfer：以 turret／整朵雲的質量法線決定大塊受光，billow 法線只留在輪廓與細節；
  一次性 sun-view 深度圖給出平滑的雲內陰影與雲對雲投影，並以解析方式扣掉每個 billow 對自己的遮蔽。
  晨昏線暖帶、天空光藍紫陰影、只在質量輪廓上的銀邊、世界座標微浮雕，都是「畫光」。
- 遠景保留已接受的 R2 天空畫；3D 雲用同一張畫的地平線色做空氣透視，自然退入畫中。
- 近景／雲內不另做一套假雲：霧密度、雲絲、霧團、海面雲影全部由同一組 billow 查詢，保證「看到的就是穿過的」。

這不是把 B1 的畫改穩、也不是把 Animfix 的體積弄硬，而是換掉「畫面美感從哪裡來」的分工。
